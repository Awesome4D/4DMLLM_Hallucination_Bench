# LiDAR-Hallu / MLLLM_Hallucination

Companion code for **LiDAR-Hallu: Separating Answer Priors from 4D LiDAR Grounding**, ICRA 2027 submission draft, version 2.

The versioned CPU analysis reproduces strict parsing, scene-held-out priors and paired error repair from the archived benchmark outputs. The original thesis implementation is preserved separately from the analysis core. No new GPU inference is claimed.
